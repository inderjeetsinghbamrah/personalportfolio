# INDERJEET // Systems & Full-Stack Architect Portfolio

An award-winning, interactive 3D scroll-driven developer portfolio engineered with **Next.js 14 (App Router)**, **React 19**, **Three.js / WebGL**, **Tailwind CSS**, and zero-asset **Web Audio API acoustic synthesis**.

Tailored specifically to showcase high-throughput **React & Next.js** interfaces, bare-metal **Rust** microservices, and cloud-native **Kubernetes / Docker DevOps** pipelines.

---

## ⚡ Architectural Highlights

### 1. Spatial 3D Multi-Stage Engine (`ThreeCanvas.tsx`)
- **Stage 0 (Hero // Quantum Core)**: Central icosahedron crystalline reactor surrounded by 3 concentric gyroscopic rings and 2,800+ volumetric interactive particles with elastic mouse repulsion.
- **Stage 1 (Frontend // Reactive Component Tree)**: Unpacks into a 3D Virtual DOM / Server Component hierarchy connected by illuminated quadratic bezier data conduits with streaming packets.
- **Stage 2 (Systems // Rust Bare-Metal Engine)**: Precision mechanical core with spinning gear manifolds, turbine geometries, and 3D memory byte registers showcasing RAII and compile-time memory safety.
- **Stage 3 (Cloud // Distributed Global Mesh)**: Geodesic cluster globe with active regional PoP nodes (Tokyo, Frankfurt, SF, Singapore, London) and orbiting Docker / Kubernetes satellite pods.
- **Real-Time Camera Choreography**: Smooth 60 FPS spring-lerped camera interpolation mapped directly to user scroll position.

### 2. Audio-Haptic Synthesizer (`sound.ts`)
- Built from scratch using native **Web Audio API** oscillator and biquad filter nodes.
- Zero external MP3 files (guarantees zero 404s, CORS blocks, or asset loading delays).
- Micro-chirps on link hover, mechanical click transients on buttons, harmonic chords on compilation, and sub-bass resonance during layer switches.
- Global Mute/Unmute toggle with live CSS-animated audio waveform equalizer in the header HUD.

### 3. Interactive Engineering Playgrounds (Anti-Generic AI Design)
- **Live Streaming SSR Visualizer**: Simulates chunked HTTP/2 transfer encoding with progressive hydration timing.
- **Rust Borrow Checker Simulator**: Interactive memory reference tester demonstrating how the Rust compiler catches concurrency data races (`E0502`) before runtime.
- **Live Canary Deployment Orchestrator**: Triggers a simulated 5-stage automated CI/CD pipeline (Cargo test -> Docker distroless build -> K8s rolling canary -> Global CDN purge) while lighting up the 3D globe with a shockwave pulse!
- **Interactive System CLI Terminal**: Full command interpreter supporting `help`, `whoami`, `stack`, `bench`, `rust`, `deploy`, `projects`, `neofetch`, `contact`, and `clear` with command history navigation.

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ (tested on Node v24.13.0)
- npm, pnpm, or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/inderjeet/portfolio_website.git
cd portfolio_website

# Install dependencies
npm install
```

### Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) (or the port indicated in terminal) in your browser.

### Production Build
```bash
npm run build
npm start
```
